## ポーリングリスト

各ノードに対して設定された監視項目（ポーリング）の一覧です。状態の確認や一括操作が可能です。

![](/images/twsnmpfk/2023-12-02_06-03-31.png)

### テンプレートの利用
新規追加時には豊富な組み込みテンプレート（PING, SNMP, HTTP, STUN, ログ監視等）から監視項目を選択でき、設定を簡単に行えます。

![](/images/twsnmpfk/2023-12-02_06-21-01.png)

### AIポーリング設定アシスタント
新規追加・編集画面で `[AIアシスト]` ボタンをクリックすると、AI（LLM）が対話的に最適なポーリング設定を提案してくれます。「Pingの応答速度が100msを超えたら異常」「Webサーバーのレスポンスコードが200以外」「Syslogで特定エラーが出たら検知」といった自然言語の指示を入力するだけで、種別選定、単位換算、JavaScript判定スクリプト、MIB OIDの検索までを自動生成します。

![](/images/twsnmpfk/polling_assist_modal.png)

## 監視結果の確認とレポート

ポーリングレポート画面のフッターには `[AI解説]` ボタンが用意されており、メトリックの傾向や障害の分析アドバイスを受けることができます。

### 基本情報とログ
現在の状態や、過去の監視ログを一覧で確認できます。

![](/images/twsnmpfk/2023-12-02_06-26-24.png)

### ダウンタイム・SLA
ポーリングログを基に、該当ポーリングの稼働率（SLA %）、障害発生回数（継続中件数）、MTTR（平均復旧時間）、最大/累計ダウンタイムを集計表示します（ログ保存設定時）。

![](/images/twsnmpfk/polling_report_downtime.png)

### 時系列・ヒストグラム
数値データをグラフ化し、推移や分布を視覚的に把握できます。

![](/images/twsnmpfk/2023-12-02_06-28-43.png)

## ポーリングの編集と主な監視種別

ポーリングの編集画面では、対象ノードの変更、障害レベル、間隔、タイムアウト、判定スクリプト（JavaScript）などを詳細に設定可能です。

- **ログモード**: ポーリング結果ログの記録方法を指定します。「異常検知」（v2.4.0で「AI分析」から名称変更）を選択すると、定期的に機械学習アルゴリズムによって数値データの外れ値分析が行われます。
- **異常検知モード**: ログモードが「異常検知」の場合に適用するアルゴリズム（Isolation Forest, ホテリングのT2, k近傍法, マハラノビス距離等）を選択します。

![](/images/twsnmpfk/2023-12-02_05-36-35.png)

### 注目の監視種別・モード

- **STUN ポーリング (`stun`)**:
  STUNサーバーを利用して外部グローバルIPアドレスの変更を常時監視します（IPv4 / IPv6両対応）。動的IP環境や拠点間VPNの監視に有効です。
- **PING Smokeping モード (`smoke`)**:
  パラメータ `count=10,size=64` などを設定することで、1回のポーリングで複数パケットを連続送信し、`avg`（平均応答時間）、`median`（中央値）、`jitter`（ゆらぎ幅）、`loss`（パケットロス率 %）を用いた高精度な品質監視が可能です。
- **Sigmaルール脅威監視 (`sigma`) (v2.4.0)**:
  `log` 監視の `sigma` モードおよび組み込みテンプレート「Syslog脅威検知(Sigma)」により、受信したログストリームに対するリアルタイムなサイバー攻撃・脅威検知を実行できます。データフォルダー（`datastore/sigma`）に独自のSigmaルールファイル（YAML）を配置するだけで自動ロードされます。

```javascript
// スクリプト例: パケットロス10%未満 かつ ジッター50ms未満なら正常
loss < 10.0 && jitter < 50 * 1000 * 1000
```

### 多彩な異常検知アルゴリズム (v2.4.0)

ポーリング結果の数値推移から通常と異なる振る舞いを検知するアルゴリズムが大幅に拡充されました（旧「AI分析」から「異常検知」へ統一）。設定画面でノードやポーリング特性に合わせた最適な方式を選択できます。

* **基本統計 / Z-Score**: 正規分布を仮定した標準偏差による基本判定。
* **ホテリング理論 (Hotelling's T2)**: 多変量データの外れ値を確率論的に検出。
* **マハラノビス距離 (Mahalanobis Distance)**: 変数間の相関を考慮した距離尺度による検知。
* **k近傍法 (k-NN) / LOF (Local Outlier Factor)**: 密度ベースで局所的な孤立度・外れ値を検出。
* **Isolation Forest**: 決定木をランダムに分割して外れ値を高速分離。
* **オートエンコーダー (Autoencoder)**: ニューラルネットワークの次元圧縮・再構成誤差を利用した非線形異常検知。
* **LSTM (Long Short-Term Memory)**: 時系列の周期性や依存関係を学習し、将来予測誤差から突発的な異常を検知。
