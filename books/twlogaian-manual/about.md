# TWLogAIANを作っている理由

TWLogAIANは2022年の元日から開発を開始した
**「私のためにAIがアシストしてくれるログ分析ツール」**
です。
このツールを開発している一番の目的は私自身が実務で使うことです。
開発や保守しているソフトの問題を調査するためのログ分析に利用するのが
一番の目的です。このような目的に最適なツールを作っています。

一般的なログ分析システムと違うのは、

- 分析中だけログを保持する
- 分析が終わったら跡形もなく削除できる
- 普通のパソコンで使える
- 自分専用の全文検索のためのインデックスを作成/削除できる

というようなことだと思っています。
問題の調査のためにログを提供してもらって調査によって問題が解決したら
フォルダーを削除すれば全部消せるという感じです。
大規模なログ分析システムだと、それなりの性能のサーバーが必要ですが、
自分のパソコンで簡単に分析できるような工夫をしています。

# できること

このツールでは次のようなことが出来ます。

- **多様なログ取得**: ローカルファイル、リモート（SCP / SFTP / FTP）、Docker/Kubernetes、HTTP/Web API、Grafana Loki、Elasticsearch、TWSNMP FC、Windowsイベントログから直接取得
- **高速フィルター & AI支援**: 正規表現、簡易フィルター、AIによる正規表現クエリ考案
- **柔軟なデータ抽出**: ログからIP、ホスト名、MACベンダー、特定パターンを抽出（AIによるGrokパターン自動生成にも対応）
- **ストレージエンジンの選択**: 全文検索エンジン（Bluge）または高速キーバリューストア／カラムナー（Apache Parquet, Badger, Bbolt）への保存
- **機械学習による異常検知**: Isolation Forest、LOF、AutoEncoder、LSTM、k-NN、マハラノビス距離、Z-Scoreによる外れ値検出
- **Sigmaルール脅威検知・コンプライアンス監査 (v2.2.0)**: 75種類の組み込みルールパックによるサイバー攻撃・監査違反の自動検知とAI脅威分析
- **多彩なビジュアライズ・レポート**: ヒストグラム、時系列(2D/3D)、クラスター、FFT、世界地図、地球儀、ヒートマップ、メール詳細分析、インターバル分析、アクセス遅延分析
- **内蔵ローカルLLM (tensai & WebGPU) (v2.1.0)**: 外部サーバー不要で完全ローカル・オフライン動作するAI解説・要約生成
- **エクスポート**: 分析結果のリストやグラフをCSV, Excelファイルに簡単保存

# 分析対象のログ

このツールが対象としているログは次のようなものです。

- ローカルファイル（ZIP、TAR.GZ、BZIP2、XZ、ZSTD、EVTX、テキストなど）
- ローカルディレクトリ
- リモートファイル（SCP / SFTP / FTP転送）
- ローカル/リモートでのコマンド実行結果 (DockerやKubernetes)
- HTTP / Web APIからのログ取得
- Grafana Loki連携
- Elasticsearch連携
- TWSNMP FCに保存したログ
- Windowsイベントログ (ローカルおよびリモート)
