# NTP サーバー監視

ネットワーク上のNTPサーバーの状態および時刻同期の精度を監視します。

## 1. 概要
指定したサーバーに対してNTPクエリを送信し、応答時間や時刻のずれ（オフセット）、Stratum値などを取得します。
サーバー自体の動作確認だけでなく、ネットワークの遅延や時刻の大幅なずれを検知するのに役立ちます。

## 2. ポーリング設定
- **種別**: `ntp`
- **モード**: (空欄)
- **パラメータ**: (空欄) ※ノードのIPアドレスに対してリクエストを送ります。
- **スクリプト**: オフセットやStratum値に基づく判定。

## 3. 取得結果 (PE.Result)

- **`offset`**: サーバーとTWSNMPサーバーとの時刻の差。 (単位: ナノ秒)
- **`stratum`**: サーバーの Stratum 階層 (1〜15)。
- **`rtt`**: NTPリクエストの往復時間 (RTT)。 (単位: ナノ秒)
- **`refid`**: 参照源の識別子。

## 4. JavaScript 判定例

### 時刻のずれを監視 (1秒以内)
- **スクリプト**: `Math.abs(offset) < 1000 * 1000 * 1000`

### Stratum値による品質監視
- **スクリプト**: `stratum < 4`
（Stratum 4 以上のサーバーは信頼性が低いとみなす場合）

### 応答速度の監視
- **スクリプト**: `rtt < 100 * 1000 * 1000`
（100ミリ秒以内に応答があれば正常）

## 5. 注意点
- **ポート**: UDP 123番ポートの通信が許可されている必要があります。
- **精度**: TWSNMPサーバー自体の時刻がネットワークを通じて正しく同期されていることが、`offset` を監視する際の前提条件となります。
