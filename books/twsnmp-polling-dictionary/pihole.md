# Pi-hole 連携

Pi-holeは、ネットワーク全体のデバイスに対して広告やトラッキングをブロックするオープンソースの「DNSシンクホール」ソフトウェアです。DNSサーバーとして動作し、不要なドメインへのアクセスを遮断することで、プライバシー保護や通信量の削減を実現します。

## 概要
広告ブロックDNS「Pi-hole」のAPIと連携して、その状態や統計情報を監視するポーリングです。
この実装は、Pi-hole v6以降で導入された新しいREST APIに対応しています。

## ポーリング設定
- **種別**: `pihole`
- **パラメータ**: アクセス先のURL（例：`http://192.168.1.100` または `https://pihole.example.com`）
  - 空白の場合は `http://<ノードのIP>` が使用されます。
- **モード**: 取得したいAPIのパス（例：`stats/summary`, `info/version`, `queries` など）
  - `/api/` 以降のパスを指定します。

### 認証設定
- **パスワード**: ノードの設定にある「パスワード」を使用します。
  - Pi-holeのWebインターフェースで使用するパスワードを設定してください。
  - ポーリング実行時に自動的にログイン（`POST /api/auth`）し、セッションを取得して実行します。実行後はログアウトします。

## JavaScript
取得したJSONデータとRTT（応答時間）を利用して判定スクリプトを記述できます。

### 利用可能な変数・関数
- **`rtt`**: ログイン処理にかかった時間（ナノ秒単位の整数）
- **`jsonpath("path")`**: 取得したJSONデータから値を抽出する関数（JSONPath形式）

### 判定スクリプト例
```javascript
// 統計情報の要約を取得し、過去24時間のブロック率が10%以上か確認
var blocked = jsonpath("$.processed.percentage");
blocked >= 10.0;
```

## 注意点
- **Pi-hole v6専用**: このポーリングは `/api/auth` などのREST APIエンドポイントを使用するため、Pi-hole v5以前のAPI（`admin/api.php`）には対応していません。
- **TLS検証**: HTTPSを使用する場合、証明書の検証はスキップされます（InsecureSkipVerify: true）。
