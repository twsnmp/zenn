# 統計モード (Stats Mode)

ログ系ポーリングにおいて、一定期間内の発生件数やユニークな項目の件数を集計して判定します。

## 1. 概要
「文字が含まれるか」といった個別のログ内容の判定ではなく、指定されたポーリング間隔内での「ログのボリューム」や「出現したパターンの多様性」を監視するモードです。
短期間のログバーストや、特定条件下での異常な頻度のログ発生を検知するのに非常に有効です。

## 2. 共通設定
- **モード**: `stats`
- **対象タイプ**: `syslog`, `trap`, `netflow`, `arplog`
- **スクリプト**: 集計された変数（`count` など）を用いた判定。

## 3. 各タイプごとの集計値 (PE.Result)

### Syslog 統計
- **`count`**: 指定期間内の総受信数。
- **`error`**: 重大度が Error 以下のログ数。
- **`warn`**: 重大度が Warning のログ数。
- **`patterns`**: ログメッセージから数値やIPを正規化した後の個別パターン数。
- **`errorPatterns`**: 重大なログにおける個別パターン数。

### SNMP Trap 統計
- **`count`**: 総トラップ受信数。
- **`types`**: 受信したトラップの種類 (OID) 数。
- **`froms`**: 送信元アドレスの種類数。
- **`typeFroms`**: 種類と送信元の組み合わせの数。

### NetFlow 統計
- **`count`**: 総フロー受信数。
- **`bytes`**: 合計転送量（バイト）。
- **`IPs`**: 出現したユニークなIPアドレス数。
- **`flows`**: ユニークなフロー（双方向考慮）数。
- **`fumbles`**: TCPセッションが短い、ICMPエラーなど「不自然なフロー」の推計数。

### ARP ログ統計
- **`count`**: ARPイベント総数。
- **`IPs`**: 出現したIPアドレス数。
- **`MACs`**: 出現したMACアドレス数。

## 4. JavaScript 判定例

### エラーログの頻発を検知 (Syslog)
- **スクリプト**: `error < 10`
（エラーログが期間内に10件以上あれば異常）

## 5. 動作の仕組み
統計モードでは、内部データベースを走査して前回の実行時間から現在までのログをメモリ上で集計します。
特に **Syslog** の `patterns` 機能は、数値を `#NUM#`、IPアドレスを `#IP#` のように置き換えてから集計するため、「異なるIPからの同じ攻撃ログ」などを一つのパターンとして正確にカウントできます。
