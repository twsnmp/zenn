# STUN グローバルIP監視

STUNプロトコル（RFC 5389 / RFC 3489）を利用して、NAT配下にある監視対象やTWSNMP環境の「外部公開グローバルIPアドレス」を検出し、その変化や通信品質を監視します（v2.3.0〜）。

## 1. 概要
家庭用ルーターや社内NAT環境配下の機器は、ローカルIP（プライベートIP）しか把握できません。本ポーリングでは、外部のSTUNサーバーに軽量なUDPパケットを送信することで、NATルーターによって割り当てられた外部公開グローバルIPアドレスおよびポート番号を特定します。

**主な用途:**
- 動的グローバルIP（PPPoE/DHCP/光コラボ回線等）環境において、ISP側でグローバルIPアドレスが変更された瞬間の検知
- 意図しない回線切替（マルチWAN環境でのフェイルオーバー発生等）の把握
- STUNサーバーへの往復応答時間（RTT）を通じたインターネット回線全体の死活・遅延監視

## 2. ポーリング設定
- **種別**: `stun`
- **モード**:
  - `""` または `ipv4`（デフォルト）: IPv4（UDP4）経由で問い合わせ
  - `ipv6` または `udp6`: IPv6（UDP6）経由で問い合わせ
- **パラメータ**: 
  - 接続先STUNサーバーの `アドレス:ポート` を指定します。
  - 例: `stun.cloudflare.com:3478`、`stun.l.google.com:19302`
  - 省略時はシステムのデフォルトSTUNサーバーが使用されます。
- **スクリプト**:
  - **空欄時（デフォルト動作）**:
    前回取得したIPと今回取得したIPが異なる場合（IP変化検知）、自動的に設定した障害レベル（`warn` 等）に遷移し、イベントログ（`STUN IP changed: <oldIP> -> <newIP>`）を発行します。
  - **記述時**:
    スクリプトの評価結果が `true` で正常、`false` で障害レベルとなります。

## 3. 取得結果 (PE.Result / スクリプト変数)
ポーリング実行後、以下の値が取得され、JavaScriptスクリプト内でも変数として利用できます：

- **`ip`**: 検出された外部公開グローバルIPアドレス（文字列）。
- **`oldip`**: 前回のポーリングで取得されたグローバルIPアドレス（文字列。初回実行時は空文字列）。
- **`port`**: STUNサーバーから見えている送信元ポート番号（数値）。
- **`host`**: 検出したグローバルIPの逆引きホスト名（FQDN）。
- **`local`**: ローカル側の送信元ソケット（`IP:ポート` 形式）。
- **`rtt`**: STUNサーバーとの往復応答時間（単位: ナノ秒）。

## 4. JavaScript 判定例

### グローバルIPアドレスの変化を検知
- **スクリプト**: `oldip == '' || oldip == ip`
- 初回ポーリング時（`oldip == ''`）は正常とし、IPアドレスが変わった時のみ障害（`false`）と判定します。

### IP変化の検知に加え、応答遅延（RTT 500ms以内）も監視
- **スクリプト**: `(oldip == '' || oldip == ip) && rtt < 500 * 1000 * 1000`
- IP変更だけでなく、インターネット通信自体の極端な遅延やパケット詰まりも同時に検知します。

### 特定の固定IPアドレスまたはプレフィックスに制限されているか監視
- **スクリプト**: `ip.startsWith("203.0.113.")`
- 本来経由すべきVPNや特定の固定IP回線以外から通信が行われていないかを監査します。

## 5. 設定テンプレート例
```json
[
  {
    "Name": "STUNグローバルIP監視",
    "Type": "stun",
    "Mode": "ipv4",
    "Params": "stun.cloudflare.com:3478",
    "Script": "oldip == '' || oldip == ip",
    "Level": "warn",
    "Descr": "STUNサーバーを利用して外部公開グローバルIPv4アドレスの変化を監視"
  },
  {
    "Name": "STUNグローバルIPv6監視",
    "Type": "stun",
    "Mode": "ipv6",
    "Params": "stun.cloudflare.com:3478",
    "Script": "oldip == '' || oldip == ip",
    "Level": "warn",
    "Descr": "STUNサーバーを利用して外部公開グローバルIPv6アドレスの変化を監視"
  }
]
```

> [!TIP]
> TWSNMP FKの「アドレス管理」画面には、STUNによるグローバルIP確認ダイアログが備わっており、GeoIP（国・都市）、Google Maps（位置情報）、VirusTotal（セキュリティ評判）と連携した詳細調査がワンクリックで行えます。
