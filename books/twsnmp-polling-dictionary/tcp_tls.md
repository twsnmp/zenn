# TCP & TLS

## TCP 接続確認

特定のTCPポートに対して接続を試行し、サービスの死活および応答時間を監視します。

### 1. 概要
指定したIPアドレス・ポート番号に対して、TCPの3ウェイ・ハンドシェイクを試行します。
OSの標準的なネットワーク機能（Dial）を使用するため、エージェント不要でWebサーバー、メールサーバー、データベースなどのサービス稼働状況をチェックできます。

### 2. ポーリング設定
- **種別**: `tcp`
- **モード**: (空欄)
- **パラメータ**: ポート番号（例: `80`, `443`, `22`, `3306`）。
- **スクリプト**: （通常は不要ですが、応答時間による判定が可能です）

### 3. 取得結果 (PE.Result)
- **`rtt`**: コネクション確立までにかかった時間（ラウンドトリップタイム）。 (単位: ナノ秒)

### 4. 動作の詳細
1. 指定されたポートに `net.DialTimeout` で接続を試みます。
2. 接続が確立されれば成功とし、直ちにコネクションをクローズします。
3. 接続に失敗した場合はリトライを行い、最終的に失敗すれば異常（指定したレベル）と判断します。

### 5. JavaScript 判定例
- **スクリプト**: `rtt < 1000 * 1000 * 1000`
（1秒以内に接続が完了すれば正常）

## TLS (暗号化通信) 監視

SSL/TLSプロトコルを使用するサービスの安全性、プロトコルバージョン、および証明書の有効期限を監視します。

### 1. 概要
HTTPSやLDAPSなどの暗号化サービスに対し、TLSハンドシェイクのみを実行します。証明書がいわゆる「オレオレ証明書」でないか、脆弱なプロトコルバージョン（TLS 1.0等）が動作していないか、証明書の期限が迫っていないかを自動的にチェックできます。

### 2. ポーリング設定
- **種別**: `tls`
- **モード**:
    - `verify`: 証明書の正当性（信頼できるCAによって署名されているか）を検証します（デフォルト）。
    - `version`: 特定のプロトコルバージョンのみを許可するかチェックします。
    - `expire`: 証明書の有効期限の残日数をチェックします。
- **パラメータ**: 対象の `ホスト:ポート`（例: `www.example.com:443`）。省略時は `ノードIP:443` です。
- **スクリプト**: モードに応じて判定基準を記述します。

### 3. 取得結果 (PE.Result)
- **`version`**: 使用された TLS バージョン (TLSv1.2, TLSv1.3等)。
- **`cipherSuite`**: 交渉の結果決定された暗号化スイート名。
- **`issuer`**: 証明書の発行者名。
- **`subject`**: 証明書の主体者名。
- **`notAfter`**: 証明書の有効期限日 (YYYY/MM/DD)。
- **`valid`**: 証明書が現在有効であれば `true`、期限切れ等なら `false`。
- **`rtt`**: ハンドシェイク完了までの時間（ナノ秒）。

### 4. JavaScript 判定例
- **モード**: `expire`
- **スクリプト**: `30`
（有効期限が **30日** を切った場合に異常と判断されます。※このモードではスクリプトに数値を記述します）

## サーバー証明書モニター / 証明書レポート

### 1. 概要
サーバー証明書モニター（TWSNMP FK）および証明書レポート（TWSNMP FC）は、指定した複数のサーバー（HTTPS, LDAPS等）のSSL/TLS証明書を定期的に取得・検証し、その有効期限や安全性を一括管理する機能です。
通常のポーリングとは異なり、多数の証明書の有効期限をリスト形式で俯瞰し、期限切れが近づいた際のアラート通知などを行うのに適しています。

### 2. 状態（レベル）の判定基準 (TWSNMP FK)
TWSNMP FKでは、取得結果に基づいて以下の5段階の状態に分類されます。

- **重度 (high)**: 
    - 接続エラーが発生した。
    - 証明書が取得できない。
    - 証明書の検証（Verify）に失敗した（不正な証明書、ホスト名不一致など）。
- **軽度 (low)**: 
    - 有効期限まで **7日以内**。
- **警告 (warn)**: 
    - 有効期限まで **30日以内**。
- **情報 (info)**: 
    - 有効期間が **825日（約2年）を超える**（最近のブラウザ基準で推奨されない長い有効期間）。
    - **自己署名証明書**（SubjectとIssuerが同一）。
- **正常 (normal)**: 
    - 上記のいずれにも該当せず、正しく検証された有効な証明書。

### 3. TWSNMP FCでの同様の機能：証明書レポート
TWSNMP FCにおいても、「証明書レポート」としてほぼ同一の機能が実装されています。

- **特徴**: TWSNMP FCでは、各証明書に対して「ペナルティ」という数値を計算し、それを元に「信用スコア (1.0〜100.0)」を算出します。
- **判定項目**: 
    - エラー、検証失敗、期限切れ、長すぎる有効期間、自己署名などの項目ごとにペナルティが加算されます。
    - スコアが低い証明書を上位に表示することで、管理が必要なサーバーを容易に特定できます。
