# SSH コマンド実行監視

SSH（Secure Shell）経由で対象機器にログインし、リモートでコマンドを実行してその結果を監視します。

## 1. 概要
Linuxサーバーやネットワーク機器に対してSSH接続し、コマンドを実行します。
SNMPをサポートしていない機器や、OS固有の詳細な情報（例：`df`, `free`, `top` などの結果）を取得して監視する場合に極めて強力な手段となります。

## 2. ポーリング設定
- **種別**: `ssh`
- **パラメータ**: リモートで実行するコマンドライン（例: `cat /proc/loadavg`）。
- **抽出 (Extractor)**: 標準出力から値を抽出するためのエンジン（`getBody`, `jsonpath`, Grok）。
- **スクリプト**: 抽出された値を用いた判定。

## 3. 認証の設定
SSH接続に必要な認証情報は、各 **ノードの設定** であらかじめ定義された「SSHユーザー名」「SSHパスワード」または「SSH公開鍵」を使用します。
個別のポーリング画面ではなく、ノード基盤の設定に依存します。

## 4. 取得結果 (PE.Result)

- **`rtt`**: SSH接続確立からコマンド完了までの時間（ナノ秒）。
- **`stdout`**: 標準出力の内容（`getBody` 等で利用）。
- **(抽出値)**: `jsonpath` や Grok で指定した変数名。

## 5. JavaScript 判定例

### ロードアベレージの監視
- **パラメータ**: `cat /proc/loadavg`
- **抽出**: `Grok` (パターン内で `%{NUMBER:load1}` を定義)
- **スクリプト**: `load1 < 5.0`

## 6. 注意点
- **セキュリティ**: 監視対象機器側で、TWSNMPサーバーからのSSH接続を許可（`sshd_config` やファイアウォール）する必要があります。
- **オーバーヘッド**: SSH接続はハンドシェイクに時間がかかるため、頻繁な実行（数秒おきなど）は対象機器および監視サーバーの双方に負荷を与えます。適切なポーリング間隔を設定してください。
- **公開鍵認証推奨**: 安全性と運用の手間を考慮し、パスワード認証よりも公開鍵認証の利用を強く推奨します。
