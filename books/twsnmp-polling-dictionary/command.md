# コマンド実行監視

TWSNMPが動作しているサーバー上で外部コマンドやスクリプトを実行し、その実行結果を監視します。

## 1. 概要
標準のポーリング機能では対応できない独自の監視ロジックを、シェルスクリプトや外部ツールプログラムで実装できます。
コマンドの終了コードだけでなく、標準出力の内容を解析して数値や状態を取り出すことが可能です。

## 2. ポーリング設定
- **種別**: `cmd`
- **パラメータ**: 実行するコマンドライン（例: `ping -c 1 $IP`）。
- **抽出 (Extractor)**: 標準出力から値を抽出するためのエンジン（`getBody`, `jsonpath`, Grok）。
- **スクリプト**: 終了コードや抽出された値を用いた判定。

### 特殊変数（パラメータ内での置換）
- `$IP`: ノードのIPアドレスに置換されます。
- `$NODE`: ノード名に置換されます（スペースは `_` に置換されます）。

## 3. 取得結果 (PE.Result)

- **`exitCode`**: コマンドの終了ステータス (通常 0 は成功)。
- **`stderr`**: 標準エラー出力の内容。
- **`lastTime`**: 実行時刻。
- **(抽出値)**: `jsonpath` や Grok で指定した変数名。

## 4. 実行可能なコマンド
TWSNMPのデータフォルダ内の `cmd` ディレクトリに配置された実行ファイルまたは `.sh` スクリプトを実行できます。セキュリティ上の理由から、絶対パスでの任意コマンド実行は制限されています。

## 5. 注意点
- **リソース消費**: 外部プロセスの起動は、ネットワーククエリに比べてCPUやメモリの消費が大きいため、頻繁な実行（1秒間隔など）は避けてください。
- **タイムアウト**: コマンドが応答しなくなった場合に備え、適切なタイムアウト値を設定してください。
- **セキュリティ**: 外部から実行されるコマンドの引数に悪意のある記述が含まれないよう、スクリプト側でのバリデーションを推奨します。
