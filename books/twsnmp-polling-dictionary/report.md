# レポートスコア監視

TWSNMPは、収集したログやトラフィックを分析し、各種エンティティ（端末、ユーザー等）に対して、「普段の振る舞い」に基づく信用スコア (1.0〜100.0) を算出しています。本ポーリングでは、これらのスコアの平均値や最小値を定期的にチェックすることで、ネットワーク全体の健全性や、一部の不審な動きを統計的に把握します。

## 1. 概要
TWSNMPは、収集したログやトラフィックを分析し、各種エンティティ（端末、ユーザー等）に対して、「普段の振る舞い」に基づく信用スコア (1.0〜100.0) を算出しています。本ポーリングでは、これらのスコアの平均値や最小値を定期的にチェックすることで、ネットワーク全体の健全性や、一部の不審な動きを統計的に把握します。

## 2. ポーリング設定
- **種別**: `report`
- **モード**:
    - `device`: デバイスレポートのスコアを対象にします。
    - `user`: ユーザーレポートのスコアを対象にします。
    - `server`: サーバーレポートのスコアを対象にします。
    - `flow`: フローレポートのスコアを対象にします。
- **パラメータ**: （通常は空欄。ネットワーク全体を対象とします）
- **スクリプト**: 統計量（最小値 `min` や平均値 `mean`）を用いた判定を記述します。

## 3. 取得結果 (PE.Result)

以下の統計量が `double` 値として格納されます。

- **`min`**: 対象レポート内の最小スコア。
- **`max`**: 対象レポート内の最大スコア。
- **`mean`**: 対象レポート内の平均スコア。
- **`stddev`**: スコアの標準偏差（ばらつき）。
- **`count`**: 集計対象となったエントリ（デバイス数等）の数。

## 4. JavaScript 判定例

### 全体の信用スコアの低下を検知
- **モード**: `device`
- **スクリプト**: `mean > 50.0`
（平均スコアが 50 を下回った＝全体的に不審な活動が増えた場合にアラート）

## 5. 動作のポイント
- **スコアの意味**: スコアが 100 に近いほど「普段通り」で安全であり、0 に近づくほど「初めての通信パターン」「大量の失敗」などの不審な要素が多いことを示します。
- **動的しきい値**: AI分析と同様、スコア自体が動的に計算されるため、固定的なしきい値だけでなく `mean_last` などを用いて「前回との差分」による判定も有効です。
